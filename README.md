# 🌍 Explore the World

The **Explore the World** website is designed to showcase top travel destinations and provide an engaging user experience for potential travelers.  
It includes interconnected pages with a cohesive theme centered around **travel inspiration**, **practical trip planning**, and **stunning visual content**.

🔗 **Live Website:** [Explore the World](https://amelhalwagi.github.io/Explore-the-World/)

---

## 📖 Overview

- Multi-page HTML/CSS website  
- Pages: Home, Gallery, Top Destinations, Contact  
- Responsive layout with images, comparison tables, and a contact form  
- GIFs generated by **Sora** (note: some physics may not be accurate)  
- Tested on **Google Chrome**

---

## 🖼 Website Pages

1. **Home Page (`index.html`)**
   - Introductory section and navigation links  
   - Travel inspiration and testimonials  

2. **Gallery Page (`gallery.html`)**
   - GIFs and descriptions of iconic landmarks (Paris, Tokyo, Cape Town, Sydney, Dubai)  

3. **Top Destinations Page (`top_destinations.html`)**
   - Destination details with comparison table  

4. **Contact Page (`contact.html`)**
   - Form to collect user info and travel preferences
